# Keep Your Prompts

Keep Your Prompts is version control and deployment for prompts. This app lets your scenarios react to what happens
in a workspace (a version saved, a deploy completed, a capture in the inbox…) and search, render, create, version,
deploy and roll back prompts.

## Connect

Create a workspace API key in Keep Your Prompts under **Settings › API keys** and paste it into the connection. Use an
**editor** key created by an owner or admin for the Watch Events trigger and for the modules that change your
workspace; a viewer key can search, get and render prompts.

## Modules

- **Watch Events** (instant): registers a webhook in your workspace for the events you choose and removes it when the
  webhook is deleted in Make.
- **Search Prompts**, **Get a Prompt**, **Render a Prompt**
- **Create a Prompt**, **Save a Prompt Version**
- **Deploy Prompts**, **Roll Back an Environment**
- **Capture a Prompt**
- **Make an API Call**

Documentation: https://keepyourprompts.com/docs
